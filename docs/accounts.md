# 账户分类与做账

新账本默认建立七类零余额账户。已有账本在“账户 → 补齐缺少的类型”补齐，已有账户、流水和余额保持不变。账户可改名，也可建立子账户，例如银行卡下的各张卡、应收款下的借款人、应付款下的信用卡和贷款。

| 类型 | 用途与余额 |
|---|---|
| 现金 | 钱包现金，余额为实际持有金额 |
| 银行卡 | 储蓄卡、活期、定期等，可分别建子账户 |
| 微信／支付宝 | 零钱、余额等，可按平台拆分 |
| 投资理财 | 记录投资账户当前账面余额 |
| 应收款 | 借出、垫付或已确认但未到账的收入；待收回余额通常为正 |
| 应付款 | 信用卡、花呗、贷款和借入款；欠款为负，预存或多还为正 |
| 其他资产／负债 | 房产等其他资产、其他欠款；资产为正，负债为负 |

总资产、总负债按各账户自身余额的正负汇总，父账户合计不会重复累加子账户。账户余额覆盖全部账本；收支报表按所选账本和时间统计。

## 初始余额与盘点

已有余额填入初始余额，不再补记成收入。后续修改当前余额会自动生成“余额变更”流水，不计收支。父账户编辑的是自身余额，不含子账户。

## 应收款

- **借出／垫付**：付款账户 → 应收款，本金不计支出。
- **收回本金**：应收款 → 收款账户，本金不计收入；另收利息单独记收入。
- **登记应收收入**：确认收入并增加应收余额；以后到账用“收回本金”，避免再次记收入。
- **坏账核销**：在该应收账户记支出，减少待收余额。

例如借出 1000 元，银行卡减少 1000 元、应收增加 1000 元，净资产不变。收回本金 1000 元并另收利息 50 元时，银行卡增加 1050 元、应收减少 1000 元，仅 50 元计收入。

## 应付款

- **借入款项**：应付款 → 收款账户，形成负余额，不计收入。
- **偿还本金**：付款账户 → 应付款，减少欠款，不计支出；另付利息和费用单独记支出。
- **赊购／信用消费**：在应付账户记普通支出，消费金额增加欠款；以后还本时不重复记支出。

例如还本金 1000 元、利息 20 元，银行卡减少 1020 元，欠款减少 1000 元，仅 20 元计支出。专用收回、还本入口不能超过当前待收或欠款；预存款可用普通转账记录。

## 投资理财

- **投资申购**：付款账户 → 投资账户，本金不计支出；另付手续费单独计支出。
- **投资赎回**：填写本次转出的账面金额与扣费后实际到账金额。账面金额按本金转出，两者差额单独计收益或亏损，可选择收支分类。
- **记录收益／亏损**：单独确认收益或亏损，选择实际发生的账户。已计入投资账户的收益不要再次当作赎回收益重复记录。
- **估值／余额调整**：只修改账面余额并生成余额变更，不计收支。之后赎回的差额以当时账面金额为基准。

例如申购 1000 元、另付手续费 5 元，付款账户减少 1005 元、投资账户增加 1000 元，仅 5 元计支出。转出账面 1000 元并实际到账 1100 元，投资减少 1000 元、收款账户增加 1100 元，差额 100 元计收入。

本金、利息、费用和盈亏以独立流水显示，可分别核对分类和备注。金额均按两位小数记账。

## 原有账户兼容

旧信用卡归入应付款展示，旧“应收应付”账户按余额方向兼容展示；使用借还入口后会保留对应方向，结清后不跳组。原账户 ID、初始余额、流水、导入标记和原类型可继续读取。也可以编辑账户，明确改成新的应收款或应付款类型。
